# Brand marks

The marks of the AI products Syft Notes names, so a student sees the one they know beside its name
(Settings → Your AI and AI apps, setup's "Which do you have?", the Ask bar's "Answer with").
Downloaded from [svgl.app](https://svgl.app) on 12 October 2026, unchanged.

| File | Product | svgl's file |
| --- | --- | --- |
| `claude.svg` | Claude | `claude-ai-icon.svg` |
| `chatgpt-light.svg`, `chatgpt-dark.svg` | ChatGPT (OpenAI's mark) | `openai.svg`, `openai_dark.svg` |
| `codex-light.svg`, `codex-dark.svg` | Codex | `codex_light.svg`, `codex_dark.svg` |
| `gemini.svg` | Gemini | `gemini.svg` |
| `ollama-light.svg`, `ollama-dark.svg` | Ollama | `ollama_light.svg`, `ollama_dark.svg` |

Each mark is its owner's trademark (Anthropic, OpenAI, Google, Ollama). They're shown only to say which
product is meant, never recoloured or redrawn, and never as Syft Notes' own. A mark drawn in one ink
has a light and a dark file; the app picks by the look (`Controls/Icon.cs`, `Brands`).

A view asks for one as an icon: `<c:Icon Glyph="brand:claude" Size="18" />`.
