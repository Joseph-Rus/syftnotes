## New

* **Canvas with nothing to type, in Firefox.** When setup reaches Canvas, Syft Notes asks your browser's add-on store which version it hands out. Firefox Add-ons already has 1.8, which finds your school's Canvas by itself, so Firefox users no longer type their Canvas address. Chrome, Edge, Brave, Arc and Vivaldi still get the step where you type it once, until the Chrome Web Store has 1.8. Then they switch over by themselves, with no app update. If an older add-on checks in instead, or nothing does within a minute and a half, you're offered the address step.
* **The Canvas extension's new look.** Its popup and the page it opens when you add it wear Syft Notes' pixel s and colours.

## Fixes

* **Lectures don't go missing from their classes.**
  * A lecture filed as "cs 101" counts for the class "CS 101".
  * A lecture that couldn't be filed, or is still waiting for its notes, is said so in the library and to Claude and the other AI apps, instead of showing up nowhere.
  * On Windows, a class whose name ends in a dot or a space, or is a name Windows keeps for itself (CON, NUL, COM1…), gets a folder Windows accepts, so its lectures save.
* **Flowcharts always draw.** A chart laid out at the same moment the app first loaded its fonts could be given up on, leaving it blank until you restarted.
* **On a Mac, the recording pill stays out of your way.** Switching to another app while you record no longer pulls Syft Notes back in front. Clicking back into the library hides the pill.
* **The level meters** grow from the middle again, up and down at once.
* **On Windows**, the installed app carries none of the code its own automatic checks use.

## Good to know

* **Needs:** on a Mac, macOS 15 (Sequoia) or later, Apple silicon or Intel; on Windows, Windows 10 or 11; on Linux, a desktop with PipeWire or PulseAudio.
* **Updating:** installed copies update themselves within a few hours, when nothing is recording and you aren't typing in a lecture's notes. To update now, use Settings → General → Updates → Update now.
* **The Canvas extension** is version 1.9 here. The stores update it on their own schedule: Firefox Add-ons has 1.8, and the Chrome Web Store is still at 1.6.
* **The privacy page** has one new line under what the app contacts: it asks Google's and Mozilla's add-on stores which version of the add-on they hand out, and nothing else.
