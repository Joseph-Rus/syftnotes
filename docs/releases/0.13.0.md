## What's new

* **ChatGPT can read your lectures.** The ChatGPT app on your computer connects with one button: Settings → AI tool access → ChatGPT → Connect, then start a chat in its Codex mode and ask about your classes. It only reads. On a Mac, Reopen restarts the app for you so it picks Study Stash up.
* **Setup with nothing extra to install.** If the ChatGPT app or the Claude app is already on your Mac, guided setup uses the AI inside it, skips the sign-in when you're signed in already, and offers to let that app read your lectures.
* **Edit your notes.** Edit turns a lecture's notes into text you can fix or add to; each diagram, plot and drawing is one line (`[Diagram 1]`) that you can move or delete. Save with ⌘S (Ctrl+S on Windows). If the notes changed meanwhile, Study Stash says so before anything is replaced. What you've typed and not saved is still there after the app quits or updates.
* **Your computer's own notifications.** Study Stash's notifications are now the system's: Notification Center on a Mac, the notification centre on Windows, with Focus and Do Not Disturb respected. A Mac asks once whether to allow them. If you turn them off, only what needs you (a recording that paused by itself) still shows, as Study Stash's own card.
* **Canvas in the browser you use.** Connecting Canvas starts from your usual browser: Chrome, Edge, Brave, Arc, Opera or Vivaldi. If it can't run the extension (Safari), Study Stash says so and uses one that can. With the extension in two browsers on one computer, Study Stash asks which one you use for Canvas, and Settings → Canvas has Change browser. Firefox isn't offered yet: its add-on is waiting on Mozilla's review.
* **A tidier class home.** Record says just Record, and Record and Attach sit beside the class's name without covering it; a long name wraps. Link a folder sits with the folders already linked. On a Mac, the sidebar button and Back and Forward sit in the window's top left corner.

## Fixes

* **Links from Canvas and notes.** On Windows, a Canvas link with "&" in it was cut short, and a link written for the purpose could start a program. Links now reach the browser whole, and a link in a note or on a Canvas page only ever opens a web page or an email address.
* **Notes you edited in another app are kept.** Saving an edit in Study Stash replaces only the summary in a lecture's note file; anything else you wrote in that file stays.
* **Memory.** Setup's window and Connect Canvas's window are freed when they close (setup kept about 20 MB, Connect Canvas about 6 MB each time it was opened).
* **Clicking a Canvas link** no longer holds the window for a moment on a Mac.

## Good to know

* **Needs:** on a Mac, macOS 15 (Sequoia) or later, Apple silicon or Intel; on Windows, Windows 10 or 11.
* **Updating:** installed copies update themselves within a few hours, when nothing is recording and you aren't typing in a lecture's notes. To update now, use Settings → Your library → Library → Update now (a laptop: Settings → General → Updates), or Update now from the menu bar on a Mac.
* **Editing notes needs this version on the library too.** A library on an older Study Stash says to update it.
