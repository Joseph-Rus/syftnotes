## What's new

* **Firefox, when the add-on is already in it.** If Firefox (or Zen, LibreWolf or Waterfox) is your usual browser and you've added Study Stash for Canvas to it, connecting Canvas now has **I already have it in Firefox**: it shows the code to paste into the add-on's own button, then waits for the browser to connect. Before, the step only said Firefox couldn't run the extension yet, and there was nowhere to get the code the add-on asks for.

## Good to know

* **Getting the add-on:** it's still waiting on Mozilla's review, so Study Stash can't add it to Firefox for you yet. Until it's published, Study Stash sets Canvas up in Chrome, Edge, Brave, Arc, Opera or Vivaldi. Safari can't run it.
* **Needs:** on a Mac, macOS 15 (Sequoia) or later, Apple silicon or Intel; on Windows, Windows 10 or 11.
* **Updating:** installed copies update themselves within a few hours, when nothing is recording and you aren't typing in a lecture's notes. To update now, use Settings → Your library → Library → Update now (a laptop: Settings → General → Updates), or Update now from the menu bar on a Mac.
