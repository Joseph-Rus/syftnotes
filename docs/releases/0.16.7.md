## What's new

* **Open a class's note before it starts.** Click an event under Coming up or Up next that hasn't started yet and its note opens, named and filed for the event, without recording. Type anything you want ahead of time. Recording starts on its own when the event does, into that same note, or press Start now to start sooner. An event that's already on still starts recording when you click it. A note planned for an event that ends without being recorded, with nothing typed in it, goes away by itself.

## Fixes

* **Class menus switch classes.** Picking a class in Due's calendar menu, Home's notes menu or the week planner did nothing: the menu closed before the click reached it. Each pick now takes effect.

## Good to know

* **Needs:** on a Mac, macOS 15 (Sequoia) or later, Apple silicon or Intel; on Windows, Windows 10 or 11.
* **Updating:** installed copies update themselves within a few hours, when nothing is recording and you aren't typing in a lecture's notes. To update now, use Settings → Your library → Library → Update now (a laptop: Settings → General → Updates), or Update now from the menu bar on a Mac.
