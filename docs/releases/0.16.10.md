## Fixes

* **No empty note for an event you only clicked.** Clicking an event in Coming up or Up next before it starts opens its note. If you leave without typing anything, nothing is kept: no empty note in Unsorted, and nothing records on its own when the event starts. Once you've written something in it, the note waits for the event, records when it starts, and the event shows "notes ready" in Coming up.
* **A deleted planned note stays deleted.** A note waiting for its event exists only on your computer until it records. Deleting it used to ask only the library, so it came back a moment later. Now it's deleted from your computer too, and Undo still brings it back.

## Good to know

* **Needs:** on a Mac, macOS 15 (Sequoia) or later, Apple silicon or Intel; on Windows, Windows 10 or 11.
* **Updating:** installed copies update themselves within a few hours, when nothing is recording and you aren't typing in a lecture's notes. To update now, use Settings → Your library → Library → Update now (a laptop: Settings → General → Updates), or Update now from the menu bar on a Mac.
